# AttemptDB desktop

The installer with a window, and the menu-bar line. A macOS app shipped as
a disk image; the same code builds on Windows and Linux, where nothing is
packaged yet.

```
app/
  src/                 the main window: index.html, style.css, main.js — no framework, no bundler
  src-tauri/           the Rust shell (its own Cargo workspace)
    src/lib.rs           commands, tray, windows
    src/binary.rs        where `attempt` is, and how it gets to ~/.local/bin
    src/ui_server.rs     `attempt ui` as a child process; its URL and cookie
    binaries/            sidecars: attempt-<triple>, attempt-hook-<triple> (gitignored)
    icons/               generated by `cargo tauri icon` from assets/icon; tray.png by scripts/tray-icon.py
    tauri.conf.json      bundle: app + dmg, externalBin = the two sidecars
  scripts/sidecars.sh  build or copy the sidecars into place
  scripts/tray-icon.py the menu-bar template icon
```

## What it does, and only that

The app carries no AttemptDB logic. Every fact it shows and every change it
makes goes through the `attempt` binary it ships:

- **Probe**: `attempt setup --dry-run --json` — what the machine looks like
  and what setup would change. Drawn as-is; the page decides nothing.
- **Set up this machine**: copy the sidecars to `~/.local/bin` (the same
  place `install.sh` uses; only when nothing is there or the sidecar is
  newer), clear macOS's quarantine flag the way the installer does, then
  `attempt setup --json --source app`.
- **Open timeline**: start `attempt ui --no-open` as a child, read the URL
  it prints, open it in a second window. The child lives as long as the app.
- **Menu-bar line**: `GET /api/attention` on that server — open sessions and
  what needs you — every 30 s; before setup, `attempt status`.
- **Full doctor** and **Remove hooks**: `attempt doctor` and `attempt
  uninstall`, shown as a terminal would.

Closing the window hides the app; it stays in the menu bar until Quit.
Nothing leaves the machine: every request is to a loopback port.

## Build

```sh
app/scripts/sidecars.sh                 # release build of the CLI, placed as sidecars
cd app
cargo tauri dev                         # run it, page reloads on edit
cargo tauri build --bundles app,dmg     # src-tauri/target/release/bundle/{macos,dmg}
cargo test --manifest-path src-tauri/Cargo.toml
```

`cargo tauri` is `cargo install tauri-cli --version '^2'`. The release
workflow does the same with the release archive's binaries as sidecars; see
`docs/releasing.md`.
